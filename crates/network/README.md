## SpaceJam Network

The SpaceJam network is a QUIC-based implementation of the JAM Protocol.

Note that this crate is currently based on the crate e`litep2p`, we will only follow
the JAM specific network protocol once it gets stable in the graypaper.

### Testing

The `data/` directory contains the certificates and keys for testing.

```
data/
├── config.toml
├── client.key
├── client.pem
├── server.key
└── server.pem
```
