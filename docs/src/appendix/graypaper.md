# Appendix A - Letters in Greek Alphabet

| Letter Upper, Lower | Name    | Pronounced  | When Speaking, Sounds Like        |
| ------------------- | ------- | ----------- | --------------------------------- |
| Α, α                | Alpha   | AHL-fah     | ah                                |
| Β, β                | Beta    | VITA        | the letter v                      |
| Γ, γ                | Gamma   | GHAH-mah    | soft gargle gh                    |
| Δ, δ                | Delta   | THELTA      | hard th as in "there"             |
| Ε, ε                | Epsilon | EHP-see-lon | E as in "met"                     |
| Ζ, ζ                | Zeta    | ZEE-tah     | Z as in "zebra"                   |
| Η, η                | Eta     | EE-tah      | ee                                |
| Θ, θ                | Theta   | THITA       | soft th as in "through"           |
| Ι, ι                | Iota    | YO-tah      | ee                                |
| Κ, κ                | Kappa   | KAH-pah     | K as in "kite"                    |
| Λ, λ                | Lambda  | LAMTHA      | L as in "lamp"                    |
| Μ, μ                | Mu      | MOO         | M as in "mouse"                   |
| Ν, ν                | Nu      | NOO         | N as in "no"                      |
| Ξ, ξ                | Xi      | KSEE        | X as in "box"                     |
| Ο, ο                | Omicron | OH-mee-kron | O as in "not"                     |
| Π, π                | Pi      | PIE         | P as in "pie"                     |
| Ρ, ρ                | Rho     | ROH, ROE    | a rolled r                        |
| Σ, σ, ς             | Sigma   | SEEGH-mah   | S as in "see"                     |
| Τ, τ                | Tau     | TAHF        | T as in "top"                     |
| Υ, υ                | Upsilon | EWP-see-lon | ee                                |
| Φ, φ                | Phi     | FEE         | F as in "photo"                   |
| Χ, χ                | Chi     | KHEE        | a light gargly ch as in "challah" |
| Ψ, ψ                | Psi     | PSEE        | ps as in "chips"                  |
| Ω, ω                | Omega   | OH-MEH-ghah | somewhere between "awe" and "oh"  |
